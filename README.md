# Movie Rating Analysis Using Python

## Project Overview
Movie Rating Analysis is a data analysis project developed using Python. It analyzes movie ratings and helps identify top-rated movies and compare average ratings across different genres.

## Objectives
- Analyze movie ratings.
- Identify the top-rated movies.
- Calculate average ratings by genre.
- Clean and process movie data.
- Visualize rating patterns using charts.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
- Data cleaning and preprocessing
- Movie rating analysis
- Top-rated movie identification
- Genre-wise average rating analysis
- Data visualization using graphs

## Dataset
The project uses movie data containing fields such as:
- Movie Title
- Genre
- Rating

A sample dataset is included in the Python code. You can also use your own `movies.csv` file.

## Installation
Install the required Python libraries:

```bash
pip install pandas matplotlib seaborn
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code or another Python editor.
3. Run the Python file:

```bash
python Movie_Rating_Analysis.py
```

4. View the analysis results and generated charts.

## Expected Output
- Top-rated movies
- Average rating by genre
- Movie rating visualization charts
- Analysis results saved in the output folder
